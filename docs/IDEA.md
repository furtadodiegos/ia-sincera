# Ideia do App

Um app divertido que mistura **roast leve** com **conselhos claramente questionáveis**.

O objetivo não é ajudar de verdade, e sim:

- provocar riso
- gerar identificação
- ser compartilhável

Fluxo simples:

1. Usuário descreve uma situação
2. Escolhe um "modo"
3. Recebe:
   - um roast leve
   - um conselho ruim, porém plausível
   - um fechamento irônico

O app deve ser rápido, simples e com personalidade.
